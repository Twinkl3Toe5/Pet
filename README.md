# PET — A tiny life

A persistent, rules-based artificial-life sandbox. PET lives in a small 2D habitat, chooses actions from its needs and curiosity, explores objects, records discoveries, and retains its state between restarts.

## Run it

Requires Python 3.10+; no third-party packages are needed.

```bash
python pet.py
```

Open **http://127.0.0.1:8000** in your browser.

## What exists in Milestone 1

- A continuously running simulation loop.
- A 2D habitat with food, water, plants, stones and other objects.
- A creature with energy, hunger, curiosity and comfort.
- A transparent rule-based decision system.
- Basic exploration and discovery memory.
- SQLite persistence: stop and restart the process and PET resumes.
- A live browser dashboard with the world, needs, discoveries and recent experiences.
- The simulation runs independently of the browser tab.

## Files

- `pet.py` — simulation, persistence and local HTTP API.
- `index.html` — 2D Canvas world and observation dashboard.
- `pet.sqlite3` — created automatically at runtime; contains the creature's persistent state.

## Notes

This is an early experiment, not a claim of sentience. PET's decisions are generated by explicit rules and small learned preference values. Its local server binds to `127.0.0.1` and is not exposed to the public internet.

## Roadmap

1. Living world and persistent creature (current).
2. More varied needs, actions and environmental interactions.
3. Better memory: episodic memories and learned object properties.
4. Learning experiments and measurable behaviour changes.
5. World-building and richer observation tools.
